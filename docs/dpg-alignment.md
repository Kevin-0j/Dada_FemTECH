# Digital Public Goods alignment

How Dada meets the nine indicators of the
[Digital Public Goods Standard](https://digitalpublicgoods.net/standard/). We intend to apply for
recognition once the pilot has finished.

| Indicator                                         | How Dada meets it                                                                                                                                                                                                                                                                                |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1. Relevance to the Sustainable Development Goals | SDG 3 (good health and well-being, including maternal mental health) and SDG 5 (gender equality, including ending violence against women and girls).                                                                                                                                             |
| 2. Open licence                                   | All code is under the MIT licence ([LICENSE](../LICENSE)).                                                                                                                                                                                                                                       |
| 3. Clear ownership                                | VIPS Health Services (clinical partner) and Uwezo Link Initiative (software), as set out in the README. Copyright is held by the Dada contributors.                                                                                                                                              |
| 4. Platform independence                          | Runs on any system with Node.js; no paid or proprietary runtime is needed. Uses open protocols. The USSD and WhatsApp providers sit behind small adapters that can be swapped for others. The optional language model can be any OpenAI-compatible endpoint, including a self-hosted open model. |
| 5. Documentation                                  | README, architecture, deployment, clinical content, demo guide, contributing guide and inline documentation of every module.                                                                                                                                                                     |
| 6. Data extraction                                | Public anonymised totals at `/stats.json`. Screening and referral records are in a standard SQLite file.                                                                                                                                                                                         |
| 7. Privacy and applicable laws                    | Designed for Kenya's Data Protection Act 2019: data minimisation, encryption of phone numbers, no storage of answers, retention limits and suppression of small counts. See [SECURITY.md](../SECURITY.md).                                                                                       |
| 8. Standards and best practices                   | Published clinical instrument (EPDS), WCAG 2.2 AA accessible web pages, typed and tested code, continuous integration, Conventional Commits.                                                                                                                                                     |
| 9. Do no harm by design                           | Safe-exit on every screen, neutral wording for shared phones, danger detection before any AI, human follow-up for every risk, a written safeguarding plan ([SAFEGUARDING.md](../SAFEGUARDING.md)).                                                                                               |
